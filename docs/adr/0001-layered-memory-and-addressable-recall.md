# 分层预算与可按条目续读的记忆召回

为让 Codex 与 Claude Code 共用长期积累的本地记忆，同时限制每次进入模型上下文的信息量，存储容量、启动摘要与完整 JSON 返回分别设限；项目正文 24000、用户正文 8000、启动摘要 800、召回默认 2400 字符是可配置起点，不是已测得的最优值。召回采用关键词搜索、摘要索引和按稳定 ID 分段读取：搜索保留正文前缀，索引负责发现，正文分段必须有有效进度；当前规模优先选择无需外部服务的确定性查找，接受同义查询可能漏检的代价，不引入语义检索。分页使用 offset 与 revision，使两个宿主和调用者无需保存服务端会话即可续读；相比不透明游标，代价是调用者必须保持查询条件一致、遇到版本变化重新开始，并接受连续排序窗口可能提前结束，这些是共享接口约定，变更时需要评估客户端迁移。
