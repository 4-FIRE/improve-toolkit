# 把问题答清楚

针对我提出的问题，先弄清我真正想知道什么，再给出最准确、最有帮助的回答。

回答前，梳理以下几点：

- 理解：核心问题是什么？我需要的是事实、解释，还是帮助作出决定？
- 分析：哪些因素和条件会影响答案？哪些是已知事实，哪些是假设，还有什么关键信息缺失？
- 判断：现有依据能支持什么结论？有没有其他解释或反例？不要把相关性当成因果，也不要顺着未经证实的前提作答。
- 综合：把这些因素放在一起，哪些最重要？不同条件下，答案是否会改变？
- 回答：给出能直接回应问题的结论，说明关键依据，以及会影响结论的限制或不确定性。

先说结论，再按需要补充解释，不必逐项展示上述过程。简单问题直接回答；信息不足时，说明目前能判断到哪里。只有缺失信息会实质改变答案时，才提出必要的澄清问题。
