# 复杂记忆整理

只在相关条目冲突、并发变更、拆分迁移、容量不足或用户要求审计时使用。
普通保存的判断与核对见 [`SKILL.md`](SKILL.md)。工具 schema 定义参数及错误返回。

## 冲突与失效

以当前来源和用户明确纠正为准，只处理与本次发现相关的条目。有取代或失效证据时
替换或删除；暂时无法核验的旧事实标为待核验，不因缺少证据删除。
替换时一并核对 summary、tags 和 source，避免正文已纠正而提示仍旧。

## 并发与修复

使用召回得到的 entry_id 和 expected_revision。遇到 `REVISION_CONFLICT`，重新读取
并判断；错误返回 `committed=true` 时先检查实际状态，避免重复写入。
受污染的元数据或 ID 按 `memory` schema 的保留、清空和 repair_id 约定显式修复，
核对返回的 ID 及完整结果。工具检查仍覆盖修复后保留的字段。

## 拆分、迁移和容量

拆分或迁移先写入并核对目标条目，再取得最新版本并删除源条目。具体更新结果或
按 ID 读取用于核对变化；代表性查询用于验证以后能否找到。

容量不足时先处理重复和已证实失效的内容，再考虑合并。只有需要完整枚举时才浏览
到最后一页，分页沿用返回版本；枚举完成与事实已经核验是两件事。

整理完成于计划变更已核对、已知冲突已解决或清楚说明未解决原因。报告实际变化及
影响后续工作的缺口，无需列出每个未保存项。
