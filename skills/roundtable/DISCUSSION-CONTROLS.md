# 多轮讨论与调整

用户要求继续、深挖、核验、换席或纠偏时，沿用当前问题和仍有效的讨论记录。
接受自然语言，无需用户记忆固定口令或每轮阅读完整菜单。

- **继续／可**：采用主持人提出的下一问。
- **深挖／深入此节**：聚焦指定分歧，查清前提或反例。
- **核验**：查找支持主张的证据，更新相关结论。
- **加入／替换观点席**：调整确有独立作用的视角，先回应当前问题。
- **纠偏或新问题**：更新范围、前提或方向，指出哪些旧结论受影响。
- **收束／结束／止**：交付最终结论和未决问题。

保留一份紧凑的讨论记录：已核验事实及来源、用户给定前提、主要推断和价值选择、
关键分歧、立场变化及证据缺口。后续回复优先展示新增内容，最终结论应能独立阅读。

默认一轮后等待用户选择；用户给定的轮数、连续推进或一次完成要求优先。
用户中途更正时延续仍有效的工作，按新要求调整，不从头重演讨论。
