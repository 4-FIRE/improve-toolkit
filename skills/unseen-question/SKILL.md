# 尚未看清的问题

回看当前可见的对话，找出用户可能尚未意识到的关键问题，或一直在努力实现、却尚未明确表达的目标。

不要只回答用户已经提出的问题。留意用户反复关注的事情、对建议的纠正，以及始终没有解决的分歧。看看这些线索放在一起，是否指向一个用户还没有说清楚的问题或目标。

如果证据不足，直接说明没有发现可靠线索，不要硬造一个问题。

如果有，选出最有依据、也最能帮助当前讨论的一个：
- 指出支持这个判断的对话线索，不要只复述用户的原话。
- 说明看清它之后，可以怎样调整当前的讨论或行动。
